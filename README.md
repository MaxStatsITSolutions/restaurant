# Luna Verde — Mediterranean Restaurant Demo

A modern, elegant restaurant demo website for **Luna Verde**, a fictional Mediterranean restaurant in Plovdiv, Bulgaria. Built with React, TypeScript, and Tailwind CSS v4.

## Features

- Cinematic full-bleed hero with film-grain texture overlay
- Animated tab-based menu with staggered transitions and dual EUR/BGN pricing
- Masonry photo gallery with hover zoom effects
- Reservation form with guest-count chip selector
- Google Maps embed with dark filter
- Mobile-responsive with slide-in drawer navigation
- Reduced-motion support for accessibility

## Tech Stack

- **React 19** + **TypeScript**
- **Tailwind CSS v4** with custom `@theme` tokens
- **Vite** for bundling and HMR
- **Cormorant Garamond** / **Manrope** / **JetBrains Mono** typography

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
